About

I've been building software since I was ten years old.

It started with games. Unreal Engine blueprints, then Unity, then a slow obsession with how computers actually work underneath. That path took me through graphics, assembly, OS development, and one accidental rebuild of ASP.NET from scratch before I discovered it already existed.

Today I ship full-stack software for clients and product teams. I run a small engineering practice for commercial work, and I publish open-source .NET libraries on NuGet.

Selected work

Three things I'm proud of.

2025Open source

Singular Framework Core

A framework family for single-object persistence in .NET.

Entity Framework handles tables of objects. Singular handles the other case — one object, stored independently, with pluggable serialization, encryption, and storage.

v… C# · .NET Standard · NuGet
2025Open source

Entity Migration Framework

Version migration by graph, not by list.

Each migration registers as a directed edge. The framework finds the path from any source version to any target version. Missing paths fail at registration, not at runtime.

v… C# · .NET Standard
2025Open source

CleanerSharpApi

A base for writing cleaner, more maintainable C# APIs.

Three-layer architecture — Repository, Service, Endpoint — with shared CRUD interfaces. Slots into the ASP.NET pipeline without boilerplate.

v… C# · ASP.NET Core
