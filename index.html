About

I built a ray tracer from scratch in high school.

That's Eclipse in 2022 — project files, Java source, console output, and an 800×600 render window with a single ray-traced triangle. It took weeks of debugging to make that speck appear.

I wrote all of it from scratch — no tutorials, no libraries. Looking at the source now, there are definitely math errors. But it's the first thing I ever built without a tutorial to follow, and I've been using it as my mark since.

Today I ship full-stack software for clients. Same instinct, better tools.
